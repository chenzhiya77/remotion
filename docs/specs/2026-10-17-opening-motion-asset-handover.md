### 2.1 原始流程骨架（首轮 brief, 9c048871）

### 2.2 连贯性批评与五条方向（2054dfab #1, 设计轮的核心意见）

1. **道具定格不连贯** → 「鸭子应该放在现在标题的左边(屏幕靠左), 和标题同一行」;
2. **标题改流式** → 「这里标题应该改成流式的对话或者问题比如: "什么是Harness RAG? 这是一场关于知识的旅程"（我的设想是知识的世界）, 就有一种流动连贯的镜头感, 以及电影的叙事感」;
3. **马不等标题** → 「马不需要等标题出来后再走, 这样也会产生定格的感觉, 马从一开始就需要从左边开始走动(两个地方都在动), 移动到鸭子右侧时, 马不停, 跑动上马, 随后骑乘右行, 和流式的问题是同步进行的」;
4. **去小字** → 「当前的舞台中有很多的小字, 比较出戏, 我觉得应该去掉」;
5. **活物感与场面调度** → 「感觉没有什么想法, 没有深度(没有镜头意图 / 叙事节拍), 内容比较空, 场景内没有其他的东西, 感觉不像是处在一个场景中……缺少场面调度（mise-en-scène）/ 环境叙事（environmental storytelling）……缺少场景: 除两个角色外世界完全静止, 角色停驻时也是全静止, 元素之间是排队式时序（一个动完停住、下一个才动）」。

## 4. 运动数学契约（重生成时若要「保住设计」, 这些不变量别丢）

1. **步伐相位 = 速度积分**, 杜绝滑步/倒退: `walkPhase(t) = ((horseX(t) − HORSE_START_X) / 255) % 1`; 只需 `horseX` 单调 ⇒ 相位恒单调。
2. **鸭子屏幕反解**: 鸭子永远钉在目标屏幕位（悬浮 340 / 跑动 340→630 / 鞍位）; 内部 `tx = (screenX − horseX(t)) / K − RIG_DUCK_CENTER_X`——马动多少, 鸭的舞台内平移反向补多少。五拍所有边界 `tx/ty` 差 < 0.02px。
3. **眼态切换表**（眨眼掩护, 切换瞬间 `eye.sy → 0.02`）: `0.00 normal / 0.24 think / 1.72 wuyu / 2.13 zhuangsha / 2.36 normal`。
4. **落地缓冲关键帧 (cushion)**: `2.12 (sy1.11) → 2.18 (sy0.85, 前倾反向) → 2.26 (sy0.94) → 2.38 (sy1.0, 起跑前倾 8°)`。
5. **跃乘姿势表 (mountPose, 30fps 帧钟)**: `f0(3.15s) → f33(4.25s 落鞍) → f42` 锁定格; 空中压重心 f5、过鞍桥 f12、落鞍前伸臂 f20–28。
6. **坐鞍求解（不手填 ty）**: 鸭「稳定点」（身体底 × 垂直中线交点, 切件平移后 `(472.9, 1161.3)`）落在**马背上沿轮廓线 (topline) 下压 4px** 处 ⇒ 永不穿模、换姿势也自动贴合。`SEAT = { tx: 130, rot: 0, sx: 0.9, s: 0.45 }`。
7. **流式字幕分词表**: 第一行 `什么是 (0.14–0.62) / Harness RAG (0.52–1.38, 强调色) / ？(1.28–1.82)`; 第二行 `这是一场 (2.15–2.82) / 关于 (2.72–3.32) / 知识的旅程 (3.20–4.22, 高光)`。
8. **游标轨迹**: 第一行时沿 `y=236` 从 x495→1185; 第二行沿 `y=318` 从 x495→1028; 4.25s 后沿二次贝塞尔 `(1028,318) → 控制点(1320,410) → (horseX(5.2)+340, 978)` 俯冲入地。
9. **拉幕**: `sheetTranslate(t) = 1940 × phase(5.20, 8.90)`; 正片时钟 `journeyTimeAt = max(0, (t−5.0)×0.75)`; 镜头 8.90s 与正片轨迹误差 < 1e-6。
10. **马身/骑乘随动**: 马身摆动 `ty −7.5|sinφ|, rot 1.35sinφ`（φ=walkPhase×2π）; 卫兵腿 `leg_0/3 反向 23°`; 落鞍瞬间马身下沉 `11.5px` 弹回。

> 马体屏幕跨度公式: 显示后马体舞台跨度为 `192.1 → 1482.1`（= 件矩形 + 统一偏移）⇒ 屏幕跨度 = `horseX + [73, 563]`（73 = 192.1×0.38, 563 = 1482.1×0.38）。

### 5.6 贴地/贴背验收公式（重画素材后的硬校验）

- **落地脚底踩地面线**: `1130 + 0.45×(boot.y+boot.h+33.3−1130) + GROUND_TY = 1271.9`（舞台）⇒ 屏幕 `979.9 ≈ 980`（容差 1px）。
- **悬浮脚底踩托羽线**: 上式 − GROUND_TY + HOVER_TY ⇒ 屏幕 `342.3 ≈ 342`（容差 1.5px）。
- **鸭底贴马背**: 稳定点 x 查 topline → 交点压进 4px（求解器自动; 若新马画换了轮廓, 重做 topline 即可）。
- 马腿底（舞台）≈ 1276.9（leg_0 件底 + 偏移）, 视觉上与地面线 1272 压合。
